# First Start Up

After launching Mnema, you'll be greeting with a simple page to pick your password (unless you've opted to disable authentication).

![initial-setup.png](initial-setup.png)

Thereafter, you'll need to log in. After which you'll be greeted with your dashboard.

Start by browsing through the different setting pages and setup Mnema just how you want it. Head to the Pages page to
set up where to download content from.

![standard-dashboard.png](standard-dashboard.png)
