# File Metadata

Mnema will write metadata into all the files it creates for you. ComicInfo.xml and an .opf file for epubs. This metadata
is always taken from upstream and generally cannot be overwritten (See [](Preferences.md) for exceptions); in case of mistakes
metadata should be corrected upstream.

On the [](Monitored-Series.md) page, you can edit the metadata for a specific file by clicking the pencil icon.
This will open a modal with a few fields you can edit. As well as give you the option to insert/download upstream metadata.

Fields that have changed content since opening the form will be marked to keep track of changes.
